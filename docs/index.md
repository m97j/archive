# Archive

This directory is the static, repository-backed fallback for
[marchivej.vercel.app](https://marchivej.vercel.app). It keeps a compact portfolio reachable even
when the primary application or one of its runtime services is unavailable.

- [한국어 포트폴리오](ko/)
- [English portfolio](en/)
- [Current application architecture](architecture/platform-topology.html)
- [Deployment readiness](operations/deployment-readiness.html)
- [Static fallback operations](operations/static-fallback.html)

The fallback contains durable summaries and outbound links only. Dynamic authoring, search,
authentication, and embeds remain features of the primary application.
